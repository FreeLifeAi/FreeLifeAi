# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities in any Free Life AI Labs open-source repository or public endpoint privately by email to:

- **Security Contact**: `Contact@freelifeai.com`

Include the repository name, commit SHA or release tag, runtime version, and a minimal reproduction command or byte fixture. We acknowledge security reports within 3 business days.

- **[`FreeLifeAi/sacp`](https://github.com/FreeLifeAi/sacp/blob/main/SECURITY.md)**: Cryptographic and operational threat-model boundaries for `SACP` (`v0.1.2`).
